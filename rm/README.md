# rm/ — Rust RM backend (`nv-bionic-native`)

The driver's kernel interface: it opens the host's `/dev/nvidia*` nodes and talks to NVIDIA's kernel module
through RM ioctls (open-gpu-kernel-modules), with no NVIDIA userspace library. It builds as
`libnv_bionic_native.so` for bionic (x86_64, i686) and for the host (tests).

What it provides:

- the C ABI in `../mesa/nv_rm.h` that NVK's kernel-driver backend (`../nvkmd-rm`) calls: memory, GPU
  virtual addresses, channels, submission, synchronisation, dma-buf sharing (`src/device.rs`, `src/gpu.rs`,
  `src/rm.rs`, `src/external.rs`, `src/syncobj.rs`);
- the NVDEC video core and its C ABI `video/nv_video.h` for the Codec2 component in `../media` (`src/video/`);
- release-specific RM ABI adapters for the supported kernel module versions (`src/compat.rs`,
  `src/compat_data.rs`, generated by `tools/generate-compat.py`; see `COMPATIBILITY.md`);

Build: `../mesa/build.py` builds it together with NVK (`cargo build --no-default-features`, per target, into
`build/nv-rm-rust`). Tests: `cargo test -p nv-bionic-native` runs the CPU tests; tests that need an NVIDIA GPU are
`#[ignore]`d and run with `-- --ignored`.

The crate predates `RUST.md`; its lint debt is listed in the `#![expect(...)]` ledger at the top of each crate
root and shrinks with every change that touches an item.
